## Описание программы

*Random Task позволяет генерировать случацйны задачи на темы спорт, учебы и работы. Также оно имеет возможность добавлять свои задачи*
---
## Требования для запуска

Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
